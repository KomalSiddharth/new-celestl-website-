The challenge: the same questions, every day

The support team was spending most of its day on questions that were already answered in the product documentation. Customers asked support instead of searching, so the queue kept growing.

Hiring more people would have helped for a while, but the real issue was that good answers existed and customers were not reaching them. Harder problems waited behind a line of simple ones.

Our approach

  1. Start from real tickets. We looked at past support conversations to find the questions that came up most.
  2. Prepare the knowledge. The product docs were cleaned up, split into sections and indexed so the agent could find the right passage.
  3. Set clear limits. The agent only answers from the documentation. If the answer is not there, or the customer is frustrated, it hands over.
  4. Test before customers see it. The team tried to break it with real and tricky questions, and we tuned it until they trusted the answers.

What we built: a docs-trained AI support agent

A support agent that sits in front of the human team:

  • Answers common questions instantly, in plain language.
  • Links to the exact doc it used, so customers can read more.
  • Hands the conversation to a human, with full context, when it is unsure.
  • Updates itself when the documentation changes.
  • Shows the team which questions it could not answer, so the docs improve over time.
