# Celestl website

Static HTML site. No build step: upload the folder as-is.

## Files
- `index.html`: homepage
- `case-studies/`: three case study pages
- `blog/index.html`: blog listing
- `blog/ai-lead-routing-workflow-n8n-openai.html`: single post layout (draft text)
- `css/style.css`: base styles, hover effects, animations
- `js/main.js`: scroll reveal and contact form
- `assets/`: images
- `sitemap.xml`, `robots.txt`: for search engines

## Demo video
Open `index.html`, search for `PASTE_YOUR_VIDEO_LINK_HERE` and replace it with your Google Drive, YouTube or Vimeo link. In Drive, set sharing to "Anyone with the link". The video section stays hidden until a real link is there.

## Before going live
1. Case studies: check every detail (stack, approach, results) against the real projects.
2. Blog: the three "Builds, new tech and guides" posts are suggested topics. Only one has a page, and its text is a draft. Write the posts or hide the blog links until they exist.
3. Blog: the four founder posts link to the Substack home page. Replace with each post's own URL.
4. Contact form: currently opens the visitor's email app. Connect a form backend.
5. `privacy.html` and `terms.html` are empty placeholders.
6. `assets/glow.jpg` is the link-preview image. Replace it with a 1200x630 version that has your headline and logo.
7. Add your logo file and favicon.
8. Founder photo is 200px. Replace `assets/komal-siddharth.png` with a larger one.
9. Canonical URLs assume `https://www.celestl.in/`. Change them if the domain differs.
